# Landing page concepts

Three directions for the StreamBoss website. Each is one self-contained HTML page that reads its pictures from
`docs/screenshots/` (open the file from this folder in a browser).

- `a-remote.html`: dark, TV-first. A "pick your screen" row of tiles that works with arrow keys and shows the install steps.
- `b-layouts.html`: a showroom of the 21 layouts with a picker.
- `c-spec.html`: a product datasheet: signal-path diagram, platform table, specification list.

Nothing here is published yet. Pick one and it becomes `site/` (GitHub Pages).
